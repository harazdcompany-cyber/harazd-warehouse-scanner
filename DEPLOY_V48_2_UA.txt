HARAZD WAREHOUSE V48.2 — створення акаунтів на сайті

1. Спочатку має бути виконаний SUPABASE_V48_1_ACCESS.sql і призначений перший адміністратор.
2. Supabase Dashboard → Edge Functions → Deploy a new function → Via Editor.
3. Назва функції: warehouse-staff-admin. Вставте код з supabase/functions/warehouse-staff-admin/index.ts.
4. Залиште перевірку JWT (Verify JWT) увімкненою, якщо вона доступна. Функція також самостійно перевіряє токен і права адміністратора.
5. Натисніть Deploy.
6. У GitHub замініть index.html та app.js. style.css та config.js залиште без змін.
7. На сайті відкрийте Персонал → Додати працівника, введіть email, початковий пароль (8+ символів), ПІБ, роль, дозволи → Зберегти.
8. Працівник входить на той самий сайт зі своїм email і паролем.

ВАЖЛИВО: Не вставляйте SERVICE_ROLE_KEY в GitHub, config.js або браузерний код. Supabase Edge Functions отримують службовий ключ зі свого серверного середовища. Не зберігайте паролі в warehouse_staff.
Статус inactive у цьому випуску блокує права на захищені операції, але не обов’язково блокує сам вхід у Supabase Auth. Для повного блокування входу потрібне додаткове керування Auth.
