HARAZD WAREHOUSE V49 — ОНОВЛЕНІ КАРТКИ

На GitHub завантажте ТІЛЬКИ три файли з архіву:
  index.html
  app.js
  style.css

Замініть ними однойменні файли в корені репозиторію.
config.js, sw.js, manifest.json, SQL, Supabase Auth та Edge Functions не змінюйте.

Зміни:
- Прибрана кнопка ↗ поверх фотографії.
- Вся картка, як раніше, відкриває деталі.
- Під назвою відображається опис, а не виробник.
- Ліворуч від доступності: склад, зона, стелаж, полиця, місце.
- Місце береться з прив'язаного location_id (якщо він є) або поля place.
- Унизу: вага та «Деталі →».

Якщо місце не прив'язано до запису, показується «—».
Після оновлення GitHub виконайте Ctrl+Shift+R.
