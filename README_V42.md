# HARAZD WAREHOUSE V42 — Equipment Gallery

## Встановлення
1. Зробіть резервну копію репозиторію.
2. Замініть у корені GitHub Pages файли `index.html`, `style.css`, `app.js` файлами з цього архіву.
3. **Не замінюйте робочий `config.js`**: він уже підключений до вашого Supabase. `config.example.js` — лише шаблон.
4. Збережіть зміни (Commit), дочекайтесь GitHub Pages і оновіть сторінку Ctrl+Shift+R.

## Нове
- Візуальна галерея з фото, статусом, місцем і шкалою доступного залишку.
- Фільтри за категорією, складом, статусом; пошук за назвою, моделлю та кодами.
- Сортування за назвою, моделлю, датою, кількістю та доступністю.
- Скидання фільтрів і лічильник результатів.
- Збережений режим «Картки / Таблиця».
- Детальна картка, редагування, сканер, довідник і авторизація з V41 залишаються.

## База даних
SQL не потрібно запускати повторно: схема Supabase не змінювалася. `database.sql` у пакеті лише для довідки — НЕ запускайте його на чинній базі.

Перевірте після оновлення: авторизацію, галерею, фільтри, відкриття картки, редагування та повторне завантаження запису.
