HARAZD WAREHOUSE V46.1 — GitHub Pages

Виправлено форму створення місць: додано тип «Місце» та вибір батьківської зони/стелажа/полиці.
Підтримуються: Склад → Зона → Місце; Склад → Зона → Стелаж → Місце; Склад → Зона → Стелаж → Полиця → Місце.

Встановлення:
1. У GitHub репозиторії замініть index.html, app.js, style.css з цього архіву.
2. Не видаляйте та не замінюйте свій config.js.
3. Натисніть Commit changes та оновіть сайт Ctrl+Shift+R.
4. SQL повторно виконувати не потрібно, якщо запит створення storage_locations вже завершився Success.

Увага: редагування існуючого обладнання поки використовує текстові поля зони, стелажа та полиці. Привʼязка до нових вузлів «Місце» не реалізована. Персонал/івенти/ремонти залишаються заготовками.
