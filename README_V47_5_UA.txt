HARAZD WAREHOUSE V47.5 — групування персонального обладнання

Замініть у GitHub app.js, style.css, index.html. config.js залиште без змін. SQL не потрібен.
Однакові персональні одиниці об’єднуються за назвою, виробником, моделлю, категорією, підкатегорією та одиницею виміру. Відмінності EQ-ID, серійних номерів і розташувань не розділяють групу. Групи розгортаються для перегляду окремих EQ-ID. Загальне обладнання не групується.
Пошук і фільтри застосовуються до окремих записів перед групуванням; підсумки відповідають видимим записам.
