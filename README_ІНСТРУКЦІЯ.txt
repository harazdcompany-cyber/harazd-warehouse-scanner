HARAZD WAREHOUSE V38

1. Завантажте index.html, app.js, style.css, sw.js, manifest.json до кореня GitHub Pages, замінивши старі файли.
2. Оновіть сторінку з очищенням кешу (Ctrl+Shift+R).
3. У Google Apps Script перевірте, що функції з GOOGLE_APPS_SCRIPT_V37.gs додані до чинного проєкту, а doGet(e) обробляє action=listEquipment через harazdV37ListEquipment_(e). НЕ замінюйте весь серверний код файлом V37.
4. Якщо змінювали Apps Script, опублікуйте нову версію Web App. Перевірте права доступу.
5. Відкрийте «СКЛАД» та натисніть «Оновити». Рядок відкриває картку в сканері.

Зміни V38: після додавання форма не очищається; при виході зі сканера камера вимикається; оновлено кеш PWA.

Примітка: перевірка роботи на вашому GitHub/Google Sheets у цьому середовищі не виконувалася.
