# HARAZD WAREHOUSE V45 — Створення місць

1. Зробіть резервну копію поточних файлів сайту.
2. У Supabase SQL Editor виконайте `SUPABASE_LOCATIONS_V45.sql` один раз.
3. Завантажте `index.html`, `app.js`, `style.css` на GitHub Pages замість старих.
4. **Не замінюйте** ваш `config.js`.
5. У Довіднику виберіть склад, створіть зону, потім стелаж у зоні та полицю на стелажі.

Існуючі поля `equipment.zone`, `equipment.rack`, `equipment.shelf` залишаються текстовими. Новий довідник місць поки не прив'язує автоматично обладнання до вузлів дерева. Старе редагування місць у обладнанні збережене.

Політики RLS дозволяють змінювати місця всім авторизованим користувачам. Для обмеження прав за ролями їх потрібно посилити.
