HARAZD WAREHOUSE — ПАКУВАННЯ / ЕТАП 1

1. Збережіть резервну копію поточної гілки main та бази Supabase.
2. У Supabase → SQL Editor запустіть SETUP_PACKAGING.sql. Переконайтеся, що виконання успішне.
3. У GitHub → harazd-warehouse-scanner → main завантажте файли з ZIP у корінь репозиторію (не вкладену папку).
4. Дочекайтеся GitHub Pages. Оновіть сторінку Ctrl+Shift+R.
5. Відкрийте ПАКУВАННЯ. Створіть тестовий рек. Перевірте PK-ID, редагування, план, фактичний вміст та вкладення.
6. Для додавання обладнання введіть точний EQ-ID. Для вкладення пакування — PK-ID.

ВАЖЛИВО: Це перший робочий етап, не повний модуль. Видача на івенти, QR-сканування пакувань, перевірка фактичної комплектності, фото/документи та транзакційні переміщення ще НЕ реалізовані.
Поточна версія не гарантує контроль залишків кількісного обладнання між пакуваннями; не використовуйте її для видачі кількісних позицій без перевірки.
Для доступу використовуються права warehouse_can(equipment_view/equipment_edit). Якщо ваші ролі мають інші назви прав, політики потрібно адаптувати.
Не виконуйте SQL повторно без необхідності.
