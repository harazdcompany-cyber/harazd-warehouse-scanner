# HARAZD WAREHOUSE V40 — картка обладнання

Оновлено детальну картку, збережено всі можливості V39 та інтеграцію Supabase.

## Встановлення
1. У GitHub `harazd-warehouse-scanner` завантажте з цього ZIP файли `index.html`, `app.js`, `style.css` і `config.js` до кореня репозиторію (замініть старі).
2. Commit changes. Дочекайтеся GitHub Pages deployment.
3. Відкрийте сайт і зробіть Ctrl+Shift+R.
4. Увійдіть у систему, натисніть рядок EQ-000001, перевірте картку.
5. Натисніть «Редагувати обладнання», змініть поле, збережіть. Сторінка повторно зчитує дані з Supabase.

SQL міграція не потрібна: використовується наявна таблиця `public.equipment`.
Зміни доступні лише авторизованим користувачам відповідно до чинних RLS policies.
Не додавайте `service_role` або секретні ключі до `config.js`.
