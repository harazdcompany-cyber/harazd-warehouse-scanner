HARAZD WAREHOUSE V47 — Прив’язка обладнання до місць зберігання

1. Supabase → SQL Editor → New query: запустіть SUPABASE_V47_EQUIPMENT_LOCATION.sql.
2. Перевірте повідомлення Success. No rows returned.
3. У GitHub Pages репозиторії замініть index.html, app.js, style.css.
4. НЕ замінюйте config.js (поточне підключення до Supabase).
5. Ctrl + Shift + R на сайті.
6. У Додати обладнання: виберіть склад, потім кінцеве Місце з довідника.
7. При редагуванні старого обладнання можна вибрати нове Місце та зберегти.

Наявні текстові адреси обладнання залишаються; автоматичної міграції старих адрес на UUID немає.
SQL змінює функцію create_equipment для атомарного запису location_id.
Для перевірки збережіть тестовий запис, відкрийте його картку й перевірте Місце з довідника.
