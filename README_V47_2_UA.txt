HARAZD WAREHOUSE V47.2 — автоматичні Barcode/QR, без поля «На ремонті» у формі.

1. Supabase SQL Editor: виконайте SUPABASE_V47_2_AUTO_CODES.sql.
2. GitHub: замініть index.html, app.js, style.css. config.js НЕ замінюйте.
3. Оновіть сайт Ctrl+Shift+R.

Barcode та QR отримують значення EQ-ID при створенні нового запису, кожна персональна одиниця має свій EQ-ID. Старі коди збережено. Коди є даними для генерації зображення етикеток, не зображеннями самі по собі. Поле ремонту прибране лише з форми: repair_quantity нових записів за замовчуванням 0, наявні значення при редагуванні не змінюються. Журнал ремонтів ще не реалізовано.
