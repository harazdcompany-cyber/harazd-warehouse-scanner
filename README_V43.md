# HARAZD WAREHOUSE V43 — Unified Equipment Gallery

Оновлено візуальний стиль сторінок **Додати**, **Сканер**, **Довідник** під стиль Equipment Gallery V42.

Додано окремі сторінки **Персонал**, **Івенти**, **Ремонти** у тому самому дизайні. Це наразі інформаційні макети: для запису даних у цих розділах потрібна додаткова схема Supabase.

Функції V42, авторизація, сканер, робота з обладнанням і довідниками збережені в незміненому `app.js`.

## Встановлення
1. Завантажте `index.html`, `style.css`, `app.js` у корінь репозиторію GitHub Pages із заміною.
2. Не змінюйте чинний `config.js` із URL та публічним ключем Supabase.
3. Після публікації оновіть сторінку з очищенням кешу (Ctrl+Shift+R).
4. SQL міграції для цього оновлення не потрібні.

Примітка: фактичну роботу з вашим Supabase слід перевірити на опублікованому сайті.
