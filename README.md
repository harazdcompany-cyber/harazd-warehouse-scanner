# HARAZD WAREHOUSE — ADD RIGHT PANEL

Ця версія відкриває сторінку **ДОДАТИ** прямо в основному правому блоці HARAZD WAREHOUSE — так само, як модуль сканера.

## Поведінка

- ліве меню залишається на місці;
- натискання **ДОДАТИ** відкриває модуль у правому контентному блоці;
- всередині підтягується робоча Apps Script форма:
  `https://script.google.com/macros/s/AKfycbytXZesXbry1qyynsnGGcBPj2vaomE5CPYG65h1A2fPZZNxUQ-G0u_fpxE3IwxHjHM8/exec?page=add`
- є кнопка **Відкрити окремо**;
- сканер та інші модулі не змінюються;
- Service Worker cache: v14.
