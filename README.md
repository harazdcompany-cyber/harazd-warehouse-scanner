# HARAZD WAREHOUSE V40 — редагування картки

1. Завантажте `index.html`, `app.js`, `style.css`, `manifest.json`, `sw.js` у GitHub Pages репозиторій, замінивши старі.
2. У Google Apps Script замініть код файлу `12_ScannerAPI.gs` на однойменний файл з цього пакета. Інші файли Apps Script не змінюйте.
3. Deploy → Manage deployments → Edit → New version → Deploy. Переконайтеся, що сайт використовує URL нового /exec розгортання.
4. Оновіть сайт Ctrl+Shift+R, відкрийте Склад → картка → Редагувати.

Увага: API оновлення працює через JSONP GET, як і наявний API додавання. Для публічного сайту цей механізм **не має захисту від сторонніх записів**. Перед реальним використанням обмежте доступ і перенесіть запис на автентифікований сервер. Також редагування категорії/розташування не перебудовує автоматично групування рядків; за потреби виконайте перебудову складу в Sheets.
