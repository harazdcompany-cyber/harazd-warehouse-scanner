# HARAZD WAREHOUSE

Головна сторінка HARAZD WAREHOUSE для GitHub Pages.

## Перед запуском
1. Відкрийте `app.js`.
2. Замініть `ВСТАВ_СЮДИ_РОБОЧИЙ_URL_APPS_SCRIPT_EXEC` на актуальний URL Google Apps Script Web App, що закінчується на `/exec`.
3. Завантажте файли в корінь репозиторію `harazd-warehouse`.
4. Увімкніть GitHub Pages: branch `main`, folder `/ (root)`.

Очікувана адреса:
https://harazdcompany-cyber.github.io/harazd-warehouse/
