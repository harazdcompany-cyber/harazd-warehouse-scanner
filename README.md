# HARAZD WAREHOUSE V42 — діагностика довідників

Виправлено помилковий зелений статус при порожній відповіді `formData`.

1. Замініть на GitHub файли `app.js`, `index.html`, `style.css`, `sw.js`, `manifest.json` (за потреби). Основне виправлення — в `app.js`.
2. В Apps Script переконайтеся, що `12_ScannerAPI.gs` містить обробник `action=formdata`, збережіть та створіть **нову версію** Web App.
3. Перевірте адресу з `index.html`: `.../exec?action=formData`. Має повернути `success:true` і непорожній `categories`.
4. Оновіть сайт Ctrl+Shift+R. Якщо список не заповниться, сайт тепер покаже повідомлення про відсутні дані, замість хибного зеленого статусу.

Увага: зміна коду не гарантує виправлення, якщо GitHub Pages звертається до старого розгортання Apps Script. Не публікуйте відкритий API запису без авторизації.
