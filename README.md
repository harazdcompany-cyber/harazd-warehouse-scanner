# HARAZD WAREHOUSE — Add Equipment Latest Design

Ця версія повторює останній затверджений макет.

Розкладка:
- Найменування — на всю ширину.
- Опис — під найменуванням, збільшена висота.
- Категорія / Підкатегорія / Тип обліку — 3 колонки.
- Модель / Одиниця виміру — 2 колонки.
- Кількість / Склад / Зона — 1/2 + 1/4 + 1/4.
- Стелаж / Полиця / Виробник / Пакування — 4 колонки.
- Вага / Ціна / Оренда / Серійний ID — 4 колонки.
- Barcode / QR — 2 колонки.
- Фото — окремим рядком на всю ширину.
- ДОДАТИ ОБЛАДНАННЯ — перша кнопка зліва.
- Очистити — друга.

Всі існуючі ID, name, onchange та onsubmit збережені, тому поточна JS-логіка продовжує працювати.

Після завантаження файлів у GitHub:
1. Commit changes.
2. Зачекати 1–2 хвилини.
3. Ctrl + F5.
