# HARAZD WAREHOUSE — Final Approved Design

Ця версія повторює затверджений дизайн сторінки «ДОДАТИ ОБЛАДНАННЯ».

Порядок полів:
1. Найменування
2. Опис
3. Категорія / Підкатегорія
4. Тип обліку / Модель
5. Одиниця виміру / Кількість
6. Склад / Зона / Стелаж / Полиця
7. Виробник / Пакування / Вага / Ціна
8. Оренда / Серійний ID / Barcode
9. QR / Штрихкод / Фото

Кнопка «ДОДАТИ ОБЛАДНАННЯ» розташована першою зліва, «Очистити» — другою.

Функціональні ID, name, onchange та onsubmit збережені, тому поточний JavaScript для dropdown-ів і API продовжує використовувати ті самі елементи.

Завантажте всі 5 файлів поверх існуючих у GitHub і після оновлення Pages виконайте Ctrl+F5.
